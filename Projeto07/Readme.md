# Web Data Analytics – Projeto 07

## 📊 Visão Geral
Este projeto faz parte da série **Web Data Analytics** e corresponde ao **Projeto 07**, cujo foco principal foi a utilização de **Web Scraping** para coleta, tratamento e análise de dados de uma pagina na web.  

O objetivo foi demonstrar como extrair informações de páginas online de forma automatizada e autorizada com as devidas permissões, estruturá-las em um formato adequado e realizar análises exploratórias para gerar insights relevantes.

---

## 🛠️ Tecnologias Utilizadas
- **Python 3.x**
- **Bibliotecas principais:**
  - `requests` – para requisições HTTP
  - `BeautifulSoup` – para parsing de HTML
  - `pandas` – para manipulação e análise de dados
 
---

## 📂 Estrutura do Projeto

📈 Resultados
- Extração automatizada de dados de páginas web.
- Estruturação dos dados em formato tabular (CSV/Excel).
- Insights sobre o conteúdo coletado.
